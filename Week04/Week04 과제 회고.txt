Week04 완료 여부: 완료

사용한 가상환경 이름: venv (python -m venv venv로 생성)

새로 설치한 외부 라이브러리: python-dotenv (1.2.3)

환경 구성 중 발생했던 문제와 해결 방법:
- pip freeze로 requirements.txt를 만든 시점이 python-dotenv 설치 전이라서 
  라이브러리 목록이 누락됐었는데, 설치 후 다시 pip freeze > requirements.txt를 
  실행해서 해결했습니다.
- VS Code 실행 버튼(▶)으로 실행하면 계속 ModuleNotFoundError(No module named 'dotenv')가 
  발생했는데, 알고 보니 가상환경이 아닌 전역 파이썬으로 실행되고 있었습니다. 
  터미널에서 venv를 activate한 뒤 직접 python 파일명.py로 실행하니 정상 작동했습니다.
- venv/Scripts/activate가 안 먹혔던 적이 있었는데, Week04 폴더로 이동하지 않고 
  최상위 폴더에서 실행해서 venv 경로를 못 찾은 것이었습니다. cd Week04 먼저 한 뒤 
  activate하니 해결됐습니다.
- config_demo.py 파일을 만들 때 확장자(.py)가 빠진 채로 저장되어 
  "No such file or directory" 에러가 났는데, 파일명을 config_demo.py로 
  다시 지정해서 해결했습니다.
- .env 파일이 GitHub에 올라가지 않도록 .gitignore에 venv/, .env, __pycache__/, *.pyc를 
  추가했고, git status로 .env가 목록에 안 뜨는 것을 확인한 뒤 커밋했습니다.

다른 PC에서 프로젝트를 실행하려면 필요한 과정:
1. 저장소를 git clone으로 받는다
2. Week04 폴더에서 python -m venv venv로 가상환경을 새로 만든다
3. venv를 activate한다 (venv\Scripts\activate)
4. pip install -r requirements.txt로 필요한 라이브러리를 설치한다
5. .env.example을 참고해서 .env 파일을 새로 만들고 실제 값을 채운다
6. python memo_v2.py (또는 config_demo.py)로 실행한다
